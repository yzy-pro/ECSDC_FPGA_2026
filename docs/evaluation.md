# 标定评估使用说明

## 操作

1. 切换到“标定评估”。程序自动停止实时对照的设备任务，完成清理后才能开始评估；返回主页也会先停止评估，不会自动连接设备。
2. 在“评估参数”选择原始相机、FPGA 采集卡或静态图像。在“设备 / 对照 → 设备设置”选择硬件路径；静态图像不打开硬件。
3. 填写棋盘格**内角点**列数、行数和方格实际边长。默认 9×6 内角点对应 10×7 方格。当前检测器支持普通棋盘格，不支持圆点板或 ChArUco。
4. 保持图卡平整、完整入镜，绕光轴旋转约 5°，固定曝光与对焦，避免反光、端点饱和。图卡尽量占据较多画面，方格过小会导致 ROI 不足。几何评估建议关闭姿态矫正、自适应 Gamma。
5. 根据实际链路选择“原始畸变图像”或“已矫正图像”。采集卡默认选择后者，但仍须确认 FPGA 去畸变开关。已矫正模式假设输出内参与导入内参一致；若裁剪、缩放或输出内参不同，应使用实际输出内参文件，不能沿用原始参数。
6. 可导入标定参数。未导入时仍能测量直线度和相对 SFR；导入后可计算重投影残差。只有原始畸变输入才能勾选软件去畸变，作为 PC 参考。
7. 点击顶部“开始评估”。实时输入约每秒处理一张不同序号的最新原始帧，连续三次角点运动 RMS 小于 1.5 px 后自动生成结果；图卡移动后重新等待稳定。静态图像、演示图直接评估一次，不验证运动稳定性。
8. 检测成功后右侧自动进入“测量结果”，可查看曲线并导出 JSON。更改参数需先停止，再启动；停止或切换页面会清除当前报告，因此请在停止前导出。

评估 FPGA 采集卡时，如需 PC 相机继续向 FPGA 供图，可点击“副屏输出”；副屏的硬件模式要求与主页一致。若 FPGA 使用其他 HDMI 源，可在设备设置中清空 PC 原始相机。评估不启动 IMU 或主页预览，仅选中的输入按约 1 Hz 全分辨率解码；相机副屏可见时另行按需解码实时全尺寸帧。

`--demo` 启动后切换到评估页、点击开始即可使用合成棋盘格。演示结果明确标为非硬件测量；导入静态图像后，即使演示模式勾选，也优先处理所选文件。

## 指标含义

| 指标 | 测量方式 | 解释 |
| --- | --- | --- |
| 边缘直线度 RMS / P95 / 最大误差 | 在相邻角点间沿法线搜索真实灰度梯度峰值，亚像素定位；按整行/整列进行正交直线拟合 | 单位是输入图像 px；主要反映检测区域内的残余弯曲和采样噪声 |
| 角点直线度 RMS | 每行、每列角点正交直线拟合 | 辅助几何指标，不能替代真实边缘采样 |
| 网格单应拟合 RMS | 理想平面网格拟合图像角点 | 单位 px；平面投影一致性残差，不是独立标定精度 |
| 标定重投影 RMS | 使用导入的 K、D 与方格尺寸 solvePnP，再将同一组角点投影回图像 | 单位 px；同样本拟合残差，不证明标定参数准确；已矫正或软件去畸变图像使用 D=0 |
| MTF50 中位数 | 棋盘格内部最多 24 条分散的斜边，在原像素坐标取 ROI、ESF/LSF、窗函数、FFT 和导数响应补偿 | 单位 cycles/pixel，报告中保留各边完整曲线和有效性原因；只统计在 0～0.5 cy/px 内有交点的边缘 |
| 最大过冲 / 欠冲 | 归一化 ESF 超出两侧平台的最大幅度 | 百分比，辅助观察振铃或锐化；不自动判定合格 |
| 边缘有效采样率 | 有对比度且梯度峰位于采样带内部的样本数 / 尝试数 | 默认至少 80% 才给出局部直线度阈值判定 |
| 棋盘格覆盖面积 | 内角点凸包面积 / 图像面积 | 不包含外围完整方格，提示测量区域大小；不代表全画面覆盖 |

默认局部直线度阈值 RMS ≤ 0.30 px、P95 ≤ 0.50 px，可按实际验收要求修改。即使结果在阈值内，也只说明当前采样线符合所设条件，**不自动给出整机合格结论**。

SFR 拒绝过小 ROI、端点饱和、低对比度、边缘过弯/噪声过大、亚像素覆盖不足，以及不在 1.5～15° 的斜边。图卡与坐标轴完全平行时可能检测到棋盘格，但 SFR 不可用。绿色框代表有效 SFR，橙色框代表条件不足；JSON 保留每条无效边的原因。

亮度响应未知时，结果是当前编码亮度下的相对 SFR。仅在确知输入为线性或 sRGB 时选择对应模式；sRGB 模式对灰度亮度执行反响应近似。这里的算法不作为经过认证的 ISO 12233 测量。图卡印刷、照明、镜头、对焦、传感器、JPEG、RGB565、插值与 Gamma 都可能影响结果；软件去畸变也可能降低部分高频响应，不能预设 MTF50 一定提高。

当前未进行同步原图/FPGA 图配对，不计算 MTF 保持率；未实现全幅裂缝、全幅拉伸和完整光学标定验收。需要把图卡分别移到中心和边角记录多组测量，结合实际目标制定验收标准。

## 标定文件

OpenCV JSON 示例（尺寸 `[宽,高]`，默认零起点，Brown 模型）：

```json
{
  "model": "opencv_brown",
  "image_size": [1920, 1080],
  "pixel_coordinate_origin": 0,
  "camera_matrix": [[748.4469, 0, 943.9033], [0, 748.0773, 521.3963], [0, 0, 1]],
  "distortion_coefficients": [0.0099, -0.0434, 0, 0, 0]
}
```

OpenCV YAML 使用 `camera_matrix`、`distortion_coefficients` 两个 OpenCV 矩阵节点，以及数值 `image_width`、`image_height`；坐标为零起点。畸变系数支持 4、5、8 项，顺序为 `k1,k2,p1,p2[,k3[,k4,k5,k6]]`。暂不支持 fisheye、非零 skew、thin-prism 或 tilt 模型。

MATLAB 导出 JSON 使用 `intrinsic_matrix_matlab`、`radial_distortion`、`tangential_distortion`、`image_size_hw`，并且必须声明 `pixel_coordinate_origin` 为 0 或 1。例如：

```json
{
  "image_size_hw": [1080, 1920],
  "intrinsic_matrix_matlab": [[748.4469, 0, 0], [0, 748.0773, 0], [944.9033, 522.3963, 1]],
  "radial_distortion": [0.0099, -0.0434],
  "tangential_distortion": [0, 0],
  "pixel_coordinate_origin": 1
}
```

解析器转置 MATLAB 内参，并在起点为 1 时将主点减 1。径向系数支持 k1、k2 或 k1、k2、k3，切向系数为 p1、p2。参数尺寸不匹配时拒绝软件去畸变，重投影显示不可用；不会自动缩放 K。无效文件会清除旧标定参数，避免误用。

导入参数用于 PC 软件参考，**不会下发 FPGA**，支持的 PC 模型也不等于 FPGA 的实际实现。报告记录文件路径、SHA256、转换约定和实际使用的 K、D，不能据此确认 FPGA 内部 ROM 参数一致。

## 报告与复现

JSON 包含版本、测量时间、原始尺寸、图卡配置、输入几何、软件参考开关、标定来源、所有几何指标、逐边 ROI / SFR / 无效原因、采样稳定性、阈值与说明。硬件输入记录本机接收序号和单调时钟；采集卡若取得新鲜串口状态会记录已应用功能掩码及 pending。这些数据没有硬件逐帧关联，不能作为同步测量或端到端延迟证据。

建议保存测量原图、图卡尺寸与位置、设备曝光/格式、FPGA 位流和功能状态，与 JSON 一起归档。当前导出不包含原图。选择相同分辨率和采集格式，先测原始输入，再测固定状态的 FPGA 输出；对比时保持图卡、焦距、照明及亮度响应设置一致。
