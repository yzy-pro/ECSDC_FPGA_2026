# Yaw/Pitch 方向与绝对姿态接入

## 用户确认的约定

2026-10-09 确认：不考虑 roll；yaw 为画面左右转动，角速度向量竖直向上为正；
pitch 为上下转动，低头为正；直接使用 IMU 输出的绝对角度，不做启动姿态归零。
UART 协议字段仍是有符号 Q2048 弧度角度，不是角速度，本工程不对其积分。

采用右手系相机坐标：x 向右、y 向下、z 向前。yaw 正方向按绕向上轴的右手旋转
解释；pitch 正方向为相机低头。输出采用逆向采样：yaw 正角对应向右取源像素，
pitch 正角对应向上取源像素。相对输入图像，补偿分别使内容向左、向下移动。
这描述的是图像补偿方向，不是相机本体运动方向。

## 已接入 RTL 的改动与范围

`imu_affine_q14` 保持三拍流水，删除 roll 计算；`undistort_rd_buf` 只保存 yaw/pitch
快照，并在输出 VS 上升沿锁存。协议仍接收六个姿态字节并计算完整校验和，
roll 字节不会影响采样坐标；这保证与参考工程的十字节协议兼容。

```text
tx = clamp(yaw * 128, -32768, 32768)        [Q14 pixel]
ty = clamp(pitch * 128, -32768, 32768)      [Q14 pixel]
sample_x = static_source_x + tx
sample_y = static_source_y - ty
```

限幅之后再对 32 位 pitch 偏移取负，避免 int16 最小值 -32768 取负溢出。
零 yaw/pitch 时，即使 roll 非零，也得到原静态采样坐标。
绝对角度直接参与每帧采样，不减第一组姿态；无有效姿态时偏移为零。

当前仍使用工程接入增益 16 像素/rad 和 ±2 像素限幅，**没有完成完整 yaw/pitch
透视矫正，也没有完成任意角度高阶任务**。镜头标定不随姿态变化。
缓存继续使用已验证的 ±4 像素包络，视频流水延迟仍为 23 拍。

检查时发现当前 GUI 保存的 `EmbFPGA.pds` 文件列表缺少四个 IMU 模块，已补回
UART、协议、CDC 和采样变换文件；其余工程设置保留。GUI 若仍显示旧文件列表，
应重新加载磁盘上的工程后再构建，避免旧列表再次覆盖修复。

## 后续大角度参考模型

`tools/audit_rotation_tiles.py --yaw-pitch Y P` 已支持忽略 roll 的浮点参考模型。
固定绝对零位的理想输出射线为 `r=(xn,yn,1)`。参考模型选择 yaw 绕参考向上轴、
pitch 绕 yaw 转动后的相机水平轴，相机到参考的旋转为：

```text
C = Ry(-yaw) * Rx(-pitch)
current_ray = transpose(C) * reference_ray
            = Rx(pitch) * Ry(yaw) * (xn,yn,1)
u_normalized = current_ray.x / current_ray.z
v_normalized = current_ray.y / current_ray.z
```

然后应用真实镜头径向/切向模型并投影到原图。这个欧拉角组合顺序是目前参考模型
的实现选择；组合运动板测应核对 IMU 融合算法是否采用相同顺序，不能仅靠单轴
正方向推出组合顺序。当前受限 RTL 不涉及该矩阵组合。

深度非正或接近零的射线被拒绝。模型还拒绝超过原始校正栅格最大归一化半径的
射线，避免把镜头多项式外推到发生折返的区域。这是数值外推保护，未经额外
镜头视场标定；被拒绝点及采样四邻点越界处计为黑边。视野之外不能恢复图像内容。

原 `20261008_rotation_tiles.md` 和 JSON 是平面内 roll 旋转的历史架构评估，
不再作为用户当前 yaw/pitch 功能的性能依据。新的逐像素评估结果为
`verification/yaw_pitch_tiles_20261009.json`，采用 128×128 输出 tile、30 fps 渲染、
60 fps 输入与显示以及假设的每突发额外 24 拍开销。

| yaw / pitch | 最大源 tile 数据 | 单输出行源行跨幅 | 估算总带宽 |
| --- | ---: | ---: | ---: |
| 0° / 0° | 41,600 字节 | 108 行 | 752.6 MB/s |
| 15° / 0° | 53,856 字节 | 178 行 | 733.1 MB/s |
| 0° / 15° | 55,616 字节 | 103 行 | 729.5 MB/s |

后两项较低的带宽同时伴随更多无有效源采样的输出点，不代表更高的有效图像性能。
RAM 深度取整、端口复制、双缓冲和输出块空间未计入表中；DDR 真实延迟、刷新和
仲裁未模拟；抽样角度不构成完整范围证明。此模型未接入 RTL。
