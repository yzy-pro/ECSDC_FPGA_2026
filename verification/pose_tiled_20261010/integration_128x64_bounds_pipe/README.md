1920×1080、2200×1125 的 60 Hz 光栅，渲染与 DDR 时钟为 100 MHz。
DDR 模型为 32 拍命令延迟、25% 随机数据停顿、读写共享的每时钟一 beat 数据通道，另施加两种刷新阻塞。

每组检查 51,840,000 个显示像素，采集、源帧身份、输出像素、所有权和 DDR 协议检查均通过。
自动曲线实际覆盖 0、1、2、3、4、6；全部 LUT 项由独立 Gamma 回归覆盖。
