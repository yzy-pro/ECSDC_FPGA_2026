## ⚠️ 重要使用须知
1. **本文档未列出的寄存器禁止写操作**，否则会造成芯片异常。
2. HDMI‑RX Controller（基地址 `0x2000`）模块，**必须使用 I2C Burst 连续读写访问**。
3. I2C 从地址由硬件 SA 引脚决定：

| SA引脚状态 | I2C从机地址 |
| ---- | ---- |
| 悬空 / 上拉电源 | `0xB2` |
| 接GND | `0x56` |

4. HDMI‑RX Controller寄存器地址计算公式：`0x2000 + 4 * N`；Burst读写固定长度=4字节。
5. 寄存器属性说明：

| 属性 | 含义 |
|------|------|
| R/W | 可读可写 |
| RO | 只读 |
| WO | 只写 |
| W1T | 写1触发，读返回无效 |

# 附录：I2C底层Burst读写示例伪代码
```c
/**
 * @brief 16位寄存器地址，8位数据，连续Burst读
 * u8_address: I2C从地址 0x56 /0xB2
 * u16_index: 寄存器起始偏移
 * u16_length: 读取字节数，HDMI‑RX控制器一般固定4
 * pu8_value: 输出缓冲区
 */
VOID mculib_i2c_burstread_16bidx8bval(UINT8 u8_address, UINT16 u16_index, UINT16 u16_length, UINT8 *pu8_value)
{
    UINT16 i;
    _i2c_start();
    if(!_i2c_write_byte(u8_address)) goto STOP;
    if(!_i2c_write_byte((UINT8)(u16_index))) goto STOP;
    if(!_i2c_write_byte((UINT8)(u16_index >> 8))) goto STOP;

    _i2c_start();
    if(!_i2c_write_byte(u8_address | 0x01)) goto STOP;

    for(i = 0; i < u16_length - 1; i++)
    {
        *pu8_value++ = _i2c_read_byte(FALSE);
    }
    *pu8_value = _i2c_read_byte(TRUE);

STOP:
    _i2c_stop();
}
