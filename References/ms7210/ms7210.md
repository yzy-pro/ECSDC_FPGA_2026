# MS7210 寄存器手册要点总结
> 芯片：MS7210｜数字输入转HDMI发送芯片
> 文档版本：B/0｜文件编号：HJ‑BMJL‑PD‑037｜2023‑03‑13
> 密级：机密｜仅供内部使用

> ⚠️ 使用强制规则：**本手册没有列出的寄存器禁止写操作，避免芯片异常。**

## 1 I2C 从机地址
由硬件 SA 引脚决定

| SA引脚状态 | I2C从地址 |
|------|------|
| SA=0（接GND） | `0x56` |
| SA=1（上拉 / 悬空） | `0xB2` |

## 2 模块与基地址总览
| 模块名称 | 基地址 | 简要功能 |
|---|---|---|
| Top MISC | `0x0000` | 全局时钟、子模块软件复位、IO上下拉、DDC开关、音频PLL选择、频率计 |
| DVIN 数字视频输入 | `0x1200` | 输入位宽/SDR‑DDR、数据重映射、同步模式、极性翻转、时序参数配置 |
| CSC 色彩空间转换 | `0x0080` | 输入输出色彩空间、BT601/BT709色域、色彩范围、422‑444滤波与UV交换 |
| PA 相位调整 | `0x1280` | 输出时钟相位调节0‑3ns，时钟翻转控制 |
| HDMI TX PHY | `0x0900` | TMDS发送PHY，预加重、驱动电流、PLL配置、模块电源下电 |
| HDMI Controller | `0x0500` | HPD状态、HDMI/DVI模式切换、音视频静音、色彩空间、像素重复系数 |
| HDMI TX Audio | `0x0530` | I2S/SPDIF音源选择，采样率、声道、位宽、I2S时序模式配置 |

## 3 Top MISC 模块（BASE:0x0000）
1. **复位机制**：TX‑PLL、音频、视频、SPDIF‑CDR等子模块，写`0`复位，写`1`退出复位正常工作。
2. **音频时钟源**：可选择I2S时钟 / SPDIF时钟；Audio‑PLL支持4种模式：纯AUDIO‑PLL、AUDIO‑DLL+PLL、纯AUDIO‑DLL、外部晶振输入PLL。
3. **IO电气配置**：数字引脚默认上拉，可独立配置下拉/上拉使能。
4. **DDC控制**：`ddc_disable` 置`1`关闭DDC通道，芯片默认关闭DDC。
5. **DVIN时钟源选择**
    - 支持pclk直接输入 / pclk二分频；
    - 锁存时钟来源可选外部PA或者TX‑PLL；
    - 8bit‑SDR、16bit‑DDR模式必须配置对应时钟选择位。
6. **PCLK频率计**：开启频率计可以读取输入像素时钟频率。

## 4 DVIN 数字视频输入模块（BASE:0x1200）
### 4.1 输入格式能力
- 工作模式：SDR / DDR；
- 位宽格式：24‑bit444、16/20/24‑bit YUV422、8/10/12‑bit YUV422；支持BT.1004、12bit DDR444；
- 同步类型：独立HS‑VS‑DE、仅VS+DE、BT656 / BT1120嵌入式SAV/EAV同步。

### 4.2 数据与同步信号处理
1. `dvin_data_sel`：输入引脚重映射，调换Y/U/V / R/G/B数据总线排布。
2. 支持：整体数据MSB‑LSB翻转、同步信号引脚互换、U/V互换、Y/C互换。
3. HS、VS、DE输入极性、输出极性都可以单独翻转。

### 4.3 时序参数
软件可配置：总行/总像素、有效行/有效像素、同步脉冲宽度、前后偏移；
支持自动检测输入HV时序，检测结果可读；
修改时序寄存器后，写`dvin_rd_trig=1`触发时序配置生效。

## 5 CSC色彩空间转换（BASE:0x0080）
1. 输入色彩空间：RGB / YUV444 / YUV422；输出色彩空间：YUV444 / YUV422。
2. 色域选择：BT601 / BT709。
3. 色彩范围：全范围(0‑255) / 视频有限范围(16‑235)。
4. 444↔422转换：可旁路滤波，支持UV/VUVU顺序交换。

## 6 PA相位调整（BASE:0x1280）
- `pa_s`：相位调节，00直通，01=1ns，10=2ns，11=3ns；
- bit2：输出时钟翻转使能。

## 7 HDMI‑TX PHY（BASE:0x0900）
1. PHY内部模块电源下电控制：bias、P2S、时钟驱动、数据驱动。
2. **预加重pre‑emphasis**：CH0/CH1/CH2、时钟通道，根据TMDS速率（<750M /750M /1.5G /3Gbps）设置预加重档位。
3. 驱动电流配置：数据通道、时钟通道独立设置驱动电流、预加重电流。
4. TX‑PLL支持前置分频、反馈后分频使能。

## 8 HDMI Controller（BASE:0x0500）
1. `hpd_status`：HPD输入检测状态，只读。
2. `dvi_en`：`1`=DVI模式，`0`=HDMI模式。
3. 软复位：TMDS时钟域复位、音频时钟域复位。
4. 静音控制：音频静音、视频静音，芯片上电默认静音。
5. 设置输出色彩空间 RGB / YUV422 / YUV444。
6. 像素重复系数：无重复 / ×2 / ×3 / ×4。

## 9 HDMI‑TX Audio（BASE:0x0530）
1. 音源选择：I2S 或者 SPDIF。
2. 采样率配置位：32K /44.1K /48K /88.2K /96K /176.4K /192K。
3. 声道配置：I2S模式，2通道设置`0001`，8通道设置`1111`。
4. I2S位宽：16bit /24bit。
5. I2S模式：左对齐(0T)、右对齐、标准I2S(1T延迟)；支持数据、LRCLK信号翻转。
6. `audio_enable`置位后硬件自动计算ACR的N/CTS参数。

## 10 软件开发关键注意事项
1. 上电流程：先执行各个模块软件复位，再退出复位，依次使能时钟。
2. DVIN：如果是DDR、BT656嵌入式同步，必须正确配置同步模式与DDR模式寄存器。
3. PHY：TMDS速率变化时，必须同步更新预加重、驱动电流参数。
4. 音频：配置采样率后设置对应sample_xxK标志位，再打开audio_enable。
5. 上电默认音视频是静音状态，需要软件关闭静音才能输出画面声音。
6. DDC默认关闭，如果需要EDID通信，需要把`ddc_disable`写0打开DDC。
